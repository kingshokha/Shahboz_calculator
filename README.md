# Shahboz Calculator 🛒

Адаптивное веб-приложение для удобного и быстрого подсчёта закупок.

## Возможности

- 📦 **Управление каталогом товаров**:
  - Создание новых товаров с указанием названия и цены за единицу.
  - Редактирование и удаление существующих товаров.
  - Сохранение каталога в памяти браузера (`localStorage`).
- 🔢 **Интерактивный калькулятор**:
  - Выпадающий список товаров с автоматическим отображением цены.
  - Поле ввода количества с кнопками быстрого изменения `[-]` и `[+]`.
  - Предпросмотр суммы выбранной позиции в реальном времени.
- 🧾 **История добавлений и смета**:
  - Отображение добавленных позиций (название, цена × количество, сумма).
  - Удаление отдельных позиций из чека.
  - Возможность очистки всего чека в один клик.
- 💰 **Итоговая сумма и экспорт**:
  - Мгновенный подсчёт итоговой суммы и общего числа позиций.
  - Кнопка быстрого копирования форматированного чека в буфер обмена.
- 📱 **Адаптивный дизайн**:
  - Оптимизирован для смартфонов, планшетов и ПК.
  - Темная современная тема с быстрой отзывчивостью.

## Запуск проекта

Проект не требует сборки и дополнительных зависимостей. Просто откройте файл `index.html` в любом современном браузере.
